TPF Partner Editor Fix
Close Operations Center, extract this ZIP and run INSTALL.bat. Select the existing TPF_ADMIN folder, then restart.
Applies to Create and Edit partner. Selecting a .txt file automatically opens its text viewer. Copy any portion manually, or use Copy all text. Text never fills fields automatically. Logo suggestions change colours only, on request.
Only ui/templates/partner_form.html changes; an automatic backup is created. No data, branding settings or credentials are changed.
