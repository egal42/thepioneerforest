TPF Operations Center — read-only online workspace

Apply to the existing TPF_ADMIN folder after the 6 October Portal Update.
Close Operations Center, extract this package, run INSTALL.bat and select TPF_ADMIN.
The installer checks the current code version and backs up changed code.
It never copies credentials or data folders. A different version stops before changes.
Restart Operations Center. Partners → select partner → View workspace · read only.
Each visit reads the current online database through the existing signed connector.
No partner password, session, invitation or allocation is created.
Refresh reloads data. Failed connections show an error, never cached balances.
Offers visible here are available to the partner; this does not confirm they read them.
The signed-in partner workspace remains separate.
