TPF Operations Center — Selected Partner Pool update

For the Partner Payment Match v2 version you have just installed.
Close the Operations Center command window. Extract this ZIP, run INSTALL.bat,
and choose your existing TPF_ADMIN folder. Restart Operations Center afterwards.
The installer checks the exact code version and creates a backup before updating.
It does not change data folders, settings, credentials, payment records or pools.

GPM payment is already recorded. Do not record it again.
Open Partner Pools > View online requests and shares.
On the paid selected offer, click “Prepare selected pool — review before planting”.
Review GPM ownership, the selected project/species, quantity and payment.
For the current GPM offer, the selected option is 716:3493:
48 Lemon / Citrus limon trees, Preservation of Mt. Elgon Ecosystem;
960 kg estimated CO2 capture over time; 300 Pi verified partner payment.
The saved offer, not the payment amount, determines this selection.

Preparing the page does not purchase trees. The final button DOES send a
Tree-Nation planting purchase after the checkbox and typed YES approval.
You may edit the pool name and public planting message before approving.
Before spending, the catalogue is refreshed. Changed cost or CO2 estimate,
insufficient stock, unpaid orders, changed selections and pool ID conflicts stop
planting for review. It never substitutes a different offer option.

After planting succeeds, return to online partner activity. Verify the planting
proof, select the new dedicated pool, and use the existing connect/publish flow.
The pool keeps the partner owner, request, selected offer and payment references.
An ambiguous or failed planting attempt is blocked from automatic repeat buying:
review its Tree-Nation result and local planting-order audit before any retry.

This is an Operations Center update only. Homepage/public-data changes remain
separate and paused. Do not install an older Admin package over this update.
